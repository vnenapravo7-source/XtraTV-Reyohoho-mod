# XtraTV Reyohoho mod

- ReYohoho для доступа к 1080p в РФ, сохранён adblock Xtra TV.
- Чат подключается только вручную и отключается при закрытии.
- Удалены загрузки, импорт файлов, офлайн-просмотр и ML Kit переводчик.
- Отключены превью, анимированные смайлы, PiP и мультистрим.
- Убрано пружинное масштабирование строк меню при перемещении фокуса.
- Отдельные APK для ARMv7, ARM64, x86 и x86_64. Выберите архитектуру Android на своём устройстве.

На TCL проверяется 1080p60. На других моделях и архитектурах требуется проверка. Работа внешнего прокси и блокировка рекламы зависят от изменений Twitch; полное отсутствие задержек интерфейса не гарантируется.
